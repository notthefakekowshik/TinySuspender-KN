Why the memory figure is an estimate

The estimated memory reclaimed figure is an estimate, not a measurement. Per-tab memory is not measurable from an extension: the only API that reports per-process memory, chrome.processes, is Dev-channel only and stays unavailable on stable Chrome or Brave (see Diagnostics). The figure is therefore the suspended-tab count multiplied by a flat 150 MB-per-tab constant — a rough stand-in for the renderer a suspension reclaims, whose real footprint varies with the page.
